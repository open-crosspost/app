## Dependency notes

- **004 requires 003**: prefill parity is meaningless while the editor's non-NEAR submit
  path is a server-side stub (`PLATFORM_UNAVAILABLE` for every platform). The connector
  bridge rewire (003) is the prerequisite.
- **007 requires 004**: the participation/browsing work assumes campaign sessions flow
  through the editor and the shared submit path.
- **006 requires 001**: plan 001 deletes `ui/src/components/ui/toast.tsx` (a drifted
  registry component); rebasing primitives (006) should happen after that deletion so
  `shadcn diff` output is clean.
- **005 and 006 are independent tracks** (application layer vs primitive layer) but both
  touch component class strings — rebase 006 before sweeping files that consume Button
  heavily where convenient, not required.
- **008 is best landed early** (it can go first) so the 005/006 sweeps only ever *shrink*
  the allowlist.

## Findings considered and rejected

- **Full 265-instance hardcoded-color sweep as one big-bang plan**: rejected in favor of
  005 (unpaired dark variants + mismatches) + 006 (primitives) + 008 (ratchet that forces
  the remainder down incrementally). A single 26-file sweep has HIGH regression risk with
  no screenshot tests to catch it.
- **Server-side campaigns/drafts/scheduling (audit finding DIRECTION-03)**: a product
  commitment, not a code fix. Campaigns, drafts, and scheduled posts all live in
  localStorage; scheduled posts only fire while the tab is open
  (`ui/src/hooks/use-scheduled-posts-executor.ts:14-20`). Deferred as a maintainer
  decision — see the audit notes; if pursued, it becomes a design/spike plan.
- **Migrating off `next-themes` / restructuring the token layer**: not worth doing.
  `ui/src/styles.css` is a clean, current shadcn/Tailwind v4 setup (`:root` + `.dark` +
  `@theme inline` all consistent, lines 6-77). The debt is entirely in the consumption
  layer.
- **`agentId: session.user.id` passed to `connectors.outlayerCall`
  (`ui/src/routes/_authenticated/campaigns/$campaignId.tsx:92`)**: LOW-confidence smell,
  not a confirmed bug — the connectors plugin keys OutLayer wallet rows by it and treats
  it as "event attribution" (`plugins/connectors/src/contract.ts:233`). Needs the
  connectors plugin owner's intent before touching. Investigate-only; not planned.
- **Landing-page glitch section hex colors** (`.supported-platforms-section`,
  `ui/src/styles.css:181-209`): deliberately theme-invariant black marketing section.
  Left as-is.
